# Contributing

Thanks for helping make these labs better for students.

Maintainer website: [www.onenova.in](http://www.onenova.in) · GitHub: [@saurabhahuja71](https://github.com/saurabhahuja71)

## Ways to help

1. **Fix a broken Quick start** — wrong command, missing dependency, outdated version.
2. **Improve a README** — clearer audience, time estimate, common errors.
3. **Report a bug** — include OS, language version, exact error text.
4. **Suggest a next lab** — especially after finishing a track.

## Pull request tips

- One concern per PR.
- Prefer beginner-readable language.
- Do not commit secrets, keys, or large binaries.
- Match the style of the target repo.

## Not in scope (for now)

- Mass refactors of old workshops without a clear student win.
- Forking huge upstream projects into this org “for learning” — link upstream instead.
